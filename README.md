# Doodle Cat · Tube U

Standalone interactive cat animation with playback, scrubbing, action inspection and a downloadable starter project. No private narration or full tutorial is published.

English is the default language. The header switches between English, Chinese and Japanese; the choice is saved locally when browser storage is available. Controls, accessibility labels, setup instructions and the copyable request all follow the selected language. The downloadable starter ZIP is shared by all three versions; its source documentation is English.

Cloudflare Pages: branch `main`, no build command, output directory `dist`. Preview: `python -m http.server 8791 --directory dist`.

The ZIP is an editable project, not an installed skill. See the linked Narration Motion Director repository for installation and attribution.
